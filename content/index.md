### Introduction
We decided to create this cheat sheet precisely because we had accumulated a fairly extensive body of knowledge and information regarding artifacts on end hosts running the Windows operating system, and ultimately decided to organize this information for use in real-world incidents.

It’s important to note that the artifacts presented here have repeatedly aided in incident analysis and are considered extremely important for understanding how an attacker interacted with the system.

### What will the cheat sheet include?
In addition, it is important to note that we focus not only on describing these artifacts but also on identifying analysis tools, explaining what we can use if these artifacts are missing or corrupted under certain circumstances, and highlighting other aspects to look for to show where we can find the same information.

This is an important point because, first and foremost, we must understand not just one source of artifacts but a whole range of them; after all, an experienced attacker can realize this at any moment and delete certain artifacts that, in one way or another, pointed to malicious activity on their part.
### Who is it intended for?
Separately, I’d like to note that this cheat sheet will be available to anyone who wants it and will be useful not only for experienced SOC/DFIR specialists but also for beginners who want to learn about system artifacts, methods for analyzing them, and, in general, understand exactly how they can store information.
### About us
We are SOC/DFIR-specialists. On this website we will try to create useful CheatSheet of DFIR artifacts which can be used by other specialists in SOC/DFIR and even Penetration Testers. The CheatSheet will be include Endpoint Artifacts of Windows OS.
